﻿# 开练 隐私政策

| 项 | 内容 |

|---|---|

| 应用名称 | 开练 |

| 包名 | `com.opengym.harmony` |

| 版本 | 1.0.0 |

| 生效日期 | 2026-11-11 |

| 适用平台 | HarmonyOS NEXT |

**一句话：开练不联网、不注册、不收集、不上传任何个人信息，所有数据只存在这台手机上。**

---

一、我们不收集什么

| 类别 | 情况 |

|---|---|

| 账号与身份信息 | **不收集**。本应用没有注册、登录、手机号、邮箱、第三方账号授权 |

| 设备信息 | **不收集**。不读取设备标识（OAID/SN/IMEI）、不读取安装列表、不做设备指纹 |

| 位置信息 | **不收集**。不申请定位权限，不做健身房定位 |

| 通讯录 / 短信 / 通话 | **不收集**，不申请该项权限 |

| 相册 / 相机 / 麦克风 | **不收集**。不申请该项权限，不做进度照片、不扫码、不录音 |

| 健康与运动数据（华为运动健康） | **默认不读取**。只有你在设置里主动点「去授权」并同意后，才**只读**运动健康里的训练记录（最近 30 天）与体重（最近一年内的最新一条），用于在设置页展示给你看；**不写入、不上传、不并入本应用的训练统计，也不落库保存**（本机只额外记一个「上次读取时间」，用来显示「最近同步」，不含任何健康数据）。不授权则完全不读 |

| 使用行为与埋点 | **不收集**。无统计 SDK、无崩溃上报 SDK、无广告 SDK |

| 网络传输 | **无**。应用不发起任何网络请求，不发 Cookie，不做云端同步 |

本应用**没有服务器**，也不存在「后端收到了你的数据」这种情况——因为没有后端。

---

二、数据存在哪里

| 数据 | 存储位置 | 用途 |

|---|---|---|

| 训练计划（routine） | 应用私有沙箱内的本地键值存储（鸿蒙 `preferences`） | 展示与编辑计划 |

| 训练记录（含每组重量、次数、RIR、时间戳） | 同上 | 历史、统计、上次对比 |

| 进行中的训练 | 同上 | 杀进程后可恢复 |

| 体重记录 | 同上 | 体重曲线 |

| 设置（单位、周起始、默认休息、对比开关） | 同上 | 按你的偏好显示 |

| 自建动作 | 同上 | 动作库 |

  • 以上数据均在**应用私有目录**内，其他应用无法读取。
  • 数据**不会**离开设备，除非你自己导出（见第三节）。
  • 应用声明支持系统备份/恢复（`allowToBackupRestore`）。若你在系统中开启了云备份或本地备份，

    • 上述数据可能被**系统备份工具**纳入备份包。该过程由鸿蒙系统执行，不经过本应用，也不会上传到本应用的任何服务器。

    关于动作演示图片与视频

    | 项 | 情况 |

    |---|---|

    | 来源 | 随**安装包内置**（打包进应用），不是从网络下载 |

    | 运行时行为 | 不下载、不缓存远程资源、**不产生任何网络请求**，也不上传任何数据 |

    | 是否采集你的信息 | 否。素材是静态资源，与你的训练数据无关，不读取、不上传 |

    | 版权 | 归 Gymvisual，经作者授权在「开练」中使用，见 [`NOTICE.md`](NOTICE.md) |

    因此「应用里有图片/视频」**不等于**「应用联网」：素材只是安装包里的一份静态文件。

    三、应用实际用到的系统能力

    以下为代码中真实调用的能力，可从工程 `entry/src/main/ets` 复核：

    | 能力 | 何时使用 | 是否涉及个人信息 |

    |---|---|---|

    | 本地存储（`@kit.ArkData` 的 preferences） | 每次保存计划、训练、体重、设置 | 否，仅存本机 |

    | 剪贴板（`@kit.BasicServicesKit` 的 pasteboard） | **仅**在你点「导出备份」时写入；**仅**在你点「导入备份」时读取一次纯文本 | 否。内容由你主动触发，应用不后台读取剪贴板 |

    | 系统提示（`promptAction`）、页面路由（`router`）、窗口与日志 | 界面交互与调试日志 | 否。日志仅本地输出，不上传 |

    | 能力 | 情况 |

    |---|---|

    | 网络（HTTP / Socket / WebView） | **未使用** |

    | 动作演示图片/视频 | **随包内置**，运行时不下载，不产生网络请求 |

    | 震动（vibrator） | **使用中**。仅用于操作反馈：拖动排序时轻震一下；后续打勾、休息结束等提示也可能使用。只触发震动马达，不采集任何信息 |

    | 运动健康读取（Health Service Kit） | **可选，只读**。需你在设置里主动授权；不授权则不读，功能显示为「未授权」，其他功能不受影响 |

    | 后台任务 / 推送通知 | **未使用** |

    | 支付 / 广告 / 分享 / 第三方登录 | **未使用** |

    四、权限申请清单

    本应用只申请 **两个权限**：一个普通权限（震动），一个需你主动授权的数据权限（运动健康）。**不申请**定位、相机、麦克风、通讯录、通知等权限。

    | 权限 | 类型 | 何时生效 | 用途 | 拒绝的后果 |

    |---|---|---|---|---|

    | `ohos.permission.VIBRATE`（震动） | **普通权限**，安装即授予，**不会弹窗** | 安装后 | 操作反馈：拖动排序时轻震一下确认已拿起；后续打勾、休息结束等提示 | 无。可在系统「设置 → 声音与振动」中关闭震动，应用照常使用 |

    | `ohos.permission.READ_HEALTH_DATA`（读取运动健康） | **需用户授权**（系统/运动健康授权页） | 仅当你点「去授权」并同意后 | **只读**运动健康里的训练记录与体重，用于设置页展示；不写入、不上传 | 无。不授权就不读，设置页显示「未授权」，其余功能不受影响 |

    补充说明：

  • **震动**：只在应用内操作时触发，不读取任何数据，也无法据此识别你。
  • **运动健康**：授权可随时在系统「设置 → 健康」或运动健康 App 中撤销，也可以在设置页点「断开连接」；撤销后应用不再读取，已展示的读数只是当时的内存数据，不落库。本机只保存「上次读取时间」这一个时间戳（用于显示「最近同步」），不含任何健康数值。
  • 除上表两项外，本应用**不申请任何其他权限**，安装后除运动健康授权外**不会出现其他权限弹窗**。

    六、你的数据怎么删

    | 想删的内容 | 操作 |

    |---|---|

    | 单次训练记录 | 历史页 → 打开该次 → 删除 |

    | 单个计划 | 计划页 → 删除该计划 |

    | 单条体重 | 统计/体重入口 → 删除该条 |

    | 自建动作 | 动作库 → 删除 |

    | 全部数据 | 设置 →「导入备份」旁不提供清空按钮时，**卸载应用**即可清除；或在系统「设置 → 应用 → 开练 → 存储」中清除数据 |

    | 已导出的备份 | 在你粘贴过的位置（备忘录、聊天等）自行删除 |

    卸载应用后，沙箱内数据随应用一并删除，本应用不留任何副本。

    八、政策更新

  • 本政策随应用版本更新。**若涉及数据处理方式的实质变化**（例如将来加入联网、云同步、账号），

    • 会在新版本首次启动时以应用内弹窗提示，并在「设置 → 关于」中展示最新版本与生效日期。

  • 仅文字修订、不改变处理方式的，随版本更新直接替换，生效日期同步更新。
  • 历史版本可在应用内「关于」页查看。

    十、声明

    1. 本政策所述「不收集、不联网、数据仅存本机」与当前代码实现一致（版本 1.0.0）：

    唯一会读到的外部数据是**你主动授权后**的运动健康训练记录与体重，**只读、只展示、不落库、不上传**。

    2. 权限只有两项：`VIBRATE`（普通权限，无弹窗）与 `READ_HEALTH_DATA`（需你主动授权）。

    3. 若将来任何版本新增联网、账号、统计、第三方 SDK 或新的权限，**必须先更新本政策并在应用内告知**，再发布该版本。
